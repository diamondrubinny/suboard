# פערים מול מערכת ניהול העבודה הקיימת של היחידה

> בסיס: מסמך "איך המערכת הקיימת בנויה ועובדת" (12.11.2026, נכתב מתוך החשבון של היחידה, קריאה בלבד) + קריאת מבנה הלוחות דרך החיבור לחשבון.
> המסמך ממפה **יכולות** (מה המשתמשים רגילים שיש), לא עיצוב או קוד. SUBoard נבנה בעיצוב ובמבנה משלו.
> סטטוס: ✅ קיים · 🟡 חלקי · ⬜ חסר · 🚫 הוחלט שלא (עם הסיבה).

## 1. מבנה הנתונים
| במערכת הקיימת | ב-SUBoard | הערה |
|---|---|---|
| Workspace → Folder → Board | 🟡 סביבות עבודה (גל U) + מועדפים + "נפתחו לאחרונה" | סביבה מסדרת בלבד, לא נותנת הרשאות; אין תיקיות |
| Groups כמיכל ויזואלי | ✅ | צבע, קיפול, שכפול קבוצה |
| Items + ערכים לפי סוג עמודה | ✅ | אימות לפי סוג בשרת |
| תת-פריטים בלוח נסתר נפרד (עמודות אחרות, "סטטוסים מתים") | ✅ אחרת בכוונה | אותן עמודות, אותו לוח, עד 5 רמות, התקדמות באב — ההחלטה שהמסמך ממליץ עליה |
| Updates, קבצים, יומן פעילות | ✅ | שרשור, אזכורים, תגובות, שחזור ערך מההיסטוריה |
| שם מותאם לשורה ("פריט ציוד") | ✅ (גל T) | בשדה ההוספה |
| מזהי עמודה יציבים, תווית עם מזהה נפרד מהטקסט | ✅ | נוסחאות ומראות נשמרות לפי מזהה |

## 2. ממשק
| במערכת הקיימת | ב-SUBoard |
|---|---|
| חיפוש גלובלי, התראות, תפריט משתמש | ✅ (חלון פקודות Ctrl+K, פעמון) |
| סרגל צד שאפשר להסתיר | ✅ (גל P) |
| כותרת לוח: אוטומציות, פעילות, חברים, קישור | ✅ |
| פריט חדש, ייבוא, חיפוש, סינון לפי אדם, מיון, הסתרת עמודות | ✅ |
| **סינון מתקדם (AND / OR)** | ✅ (גל R) — כל / אחד מהתנאים, עד 10, נשמר בתצוגה |
| Group by | ✅ (גל T) — לפי סטטוס או אנשים, נשמר בתצוגה |
| סיכום בתחתית קבוצה: סוללה לסטטוס, סכום / ממוצע | ✅ (מספרים — גל M; **סוללת סטטוס — גל R**) |
| פעולות מרובות (Batch) | ✅ |
| חלון פריט: עדכונים / קבצים / יומן | ✅ |

| "עדכון דרך דוא"ל" לכל פריט | 🚫 משטח תקיפה (זיוף שולח); דורש SPF/DKIM ושרת דואר נכנס |

## 4. סטטוס
| נושא | ב-SUBoard |
|---|---|
| תווית = מזהה + טקסט + צבע + "נחשב סגור" | ✅ |
| מחיקת תווית משאירה ערכים יתומים | ✅ **נמנע (גל R)**: תווית בשימוש אינה נמחקת בלי החלטה — העברה לתווית אחרת או ניקוי מכוון |
| תווית מושבתת (נשארת בערכים, לא לבחירה) | ✅ (גל T) |

## 5. תצוגות
טבלה ✅ · קנבן ✅ · לוח שנה ✅ · ציר זמן / גאנט ✅ · גלריית קבצים ✅ · טופס ✅ · דשבורד ✅ · מפת סיכונים ✅ (ייחודי) · תרשים בלוח 🟡 (עמוד סיכום) · מסמך / קנבס ⬜.
תצוגה = שאילתה שמורה (סינון + מיון + עמודות מוסתרות + רוחב) ✅, אישית או משותפת ✅.

## 8. API
GraphQL ציבורי, Webhooks ⬜ — לא נבנה בלי אישור מפורש (מוציא מידע מהשרת).

## 9. ההחלטות שהמסמך ביקש לקבל
1. **תת-פריטים באותה טבלה** — ✅ כך נבנה (גל J).
2. **מחיקת תווית סטטוס בלי יתומים** — ✅ גל R.
3. **יומן פעילות מהיום הראשון** — ✅ קיים; משמש ל-undo, לשחזור ערך ולביקורת.
4. **אוטומציות כמנוע אירועים** — ✅ קיים (`onItemEvent`), בנוסף למשימות מתוזמנות.
