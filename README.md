# SUBoard — מערכת ניהול עבודה ליחידת הבטיחות

מערכת לוחות עבודה (Boards) פנימית, בעברית ו-RTL, לניהול תהליכי יחידת בטיחות:
אירועים וכמעט-אירועים, סקרי מעבדות, פעולות מתקנות, הדרכות ובדיקות ציוד תקופתיות.

- **לוחות גמישים** — קבוצות, עמודות מסוגים שונים (סטטוס, אנשים, תאריך, מספר, טקסט, תיבת סימון), תצוגת טבלה וקנבן.
- **9 תבניות** מוכנות ליחידת בטיחות (כולל מלאי חומרים מסוכנים + SDS, ומפגעים ותוכניות קומה).
- **לוח בקרה** — פריטים באיחור, יעדים קרובים, משויכים אליי, תמונת מצב לכל לוח.
- **הרשאות** — מנהל מערכת / מנהל / משתמש, ובכל לוח: בעלים / עורך / צופה.
- **תיעוד** — עדכונים לכל פריט, היסטוריית שינויים ויומן אבטחה.
- **אימות דו-שלבי (MFA/TOTP)** — חובה למנהלי מערכת, קודי שחזור, איפוס ע"י מנהל.
- **התראות** — פעמון במערכת + דוא"ל (אופציונלי): שיוך לפריט, באיחור, יעד מחר.
- **קבצים מצורפים** — סריקת נוזקות (ClamAV) והסגר לפני זמינות להורדה.
- **ייצוא CSV ו-Excel, ייבוא מ-Excel/CSV** — עם מיפוי עמודות; הקובץ נקרא בדפדפן בלבד.
- **תת-פריטים, 15 סוגי עמודות** (תגיות, טווח תאריכים, התקדמות, דירוג, קישור, דוא"ל, טלפון, מזהה רץ ועוד).
- **תצוגת לוח שנה, תצוגות שמורות, מיון, הסתרת עמודות, עריכה מרובה, שכפול והעברה בין לוחות, סל מחזור עם "ביטול".**
- **חיפוש גלובלי** (Ctrl+K) ו-**@אזכורים** בעדכונים.
- **אוטומציות** "כאשר ← אם ← אז" עם מתכונים מוכנים, **SLA והסלמה** (פריט תקוע בסטטוס, N ימים לפני/אחרי יעד), יומן הרצות.
- **פריטים חוזרים** (יומי / שבועי / חודשי / שנתי) — בדיקות ציוד וסקרים תקופתיים נוצרים לבד עם יעד ואחראי.
- **דוחות מתוזמנים** לחברי לוח (במערכת + דוא"ל), **עמוד סיכום לוח**, וייצוא **ליומן (ICS)** — ללוח ול"הפריטים שלי".
- **בטיחות בשטח (גל C):** קוד **QR** לכל פריט (גיליון מדבקות להדפסה; סריקה ← כרטיס פריט לנייד עם דיווח תקלה וצילום), **צ'קליסט בדיקה** שסעיף "לא תקין" בו פותח **פעולה מתקנת מקושרת**, **מטריצת סיכון** (סבירות × חומרה) + **מפת חום**, **תחקיר מובנה** (5 למה, גורם שורש, בדיקת אפקטיביות), **מעקב תאימות** חוצה-לוחות, **טפסים פנימיים** (כולל "כל המשתמשים") ו**התקנה כאפליקציה** (PWA).
- **דוחות ותכנון (גל D):** **דשבורדים** אישיים ומשותפים (מספרים, מגמות, איחורים, עומס, תאימות, סיכונים — כל צופה רואה רק את הלוחות שלו), **ציר זמן (גאנט)** עם **תלויות** "חסום ע"י", **עומס צוות**, דוח **"מבט מנהל"** חודשי (גם בדוא"ל), ו-**PDF** לכל דוח (הדפסה מהדפדפן).
- **מודולים (גל E):** **מטריצת הדרכות** (תוקף, פערים, תזכורות, "ההדרכות שלי"), **ספריית נהלים** עם גרסאות ו**"קראתי ואישרתי"**, ו**מפגעים על תוכנית קומה**.
- **התחברות ארגונית (SSO)** ב-OpenID Connect — Microsoft Entra ID או כל ספק OIDC — ו**סנכרון משתמשים (SCIM 2.0)**. ההתחברות בסיסמה נשארת פעילה עד שה-SSO מוגדר, ואחר כך אפשר להשאיר אותה לחשבון חירום בלבד. הגדרה: [`docs/DEPLOYMENT.md`](docs/DEPLOYMENT.md) §1ה.
- **שיפורי יום-יום (גל H):** **מועדפים** ו**"נפתחו לאחרונה"**, **חלון פקודות** (Ctrl/⌘+K) וקיצורי מקלדת (`?`), **מעקב אחרי פריט** עם התראות, **תשובות לעדכונים ותגובות-אימוג'י**, **גלריית קבצים** ללוח, ו**ניהול מכשירים מחוברים** (ניתוק מכשיר / כל האחרים; admin — ניתוק משתמש).
- **תבניות ועמודות (גל I):** **שמירת לוח כתבנית הארגון** (מבנה בלבד) ויצירת לוחות ממנה, **שינוי רוחב עמודות** (עכבר, מגע ומקלדת), ועמודות **"נוצר ע"י"** ו**"עודכן לאחרונה"**.
- **התקנה בתיקייה של אתר קיים** (למשל `https://dreadlist.com/test`) עם סקריפט התקנה אחד לשרת Linux — [`docs/DEPLOYMENT.md`](docs/DEPLOYMENT.md) §1ו.
- **איפוס סיסמה עצמי** ("שכחתי סיסמה") בקישור חד-פעמי בדוא"ל — כשמוגדר SMTP; בלעדיו — איפוס ע"י מנהל המערכת.
- **תתי-משימות ונוחות (גל J):** תת-פריטים ב**קינון עד 5 רמות** (תת-פריט של תת-פריט) עם תיבת **"בוצע"**, אחראי ותאריך, **התקדמות בשורת האב**, עמוד **"המשימות שלי"** חוצה-לוחות, **ביטול פעולה (Undo)** אחרי כל עריכה, קיצורי תאריך (היום / מחר / בעוד שבוע) והעתקת קישור לפריט.
- **יוצר טפסים (גל K):** טופס חדש מאפס עם שאלות, אפשרויות ותצוגה מקדימה, או **טופס בקליק** מלוח קיים; **שיתוף בקישור ובקוד QR**; התשובות נכנסות כפריטים בלוח תשובות שנוצר אוטומטית. (מודול היתרי העבודה הוסר.)
- **טפסים בהתאמה אישית (גל L):** מרכז ניהול לכל הטפסים (שכפול, הפעלה, שיתוף, Excel), **כותרות מקטע**, **שאלות מותנות** ("הצג רק אם"), הודעת סיום מותאמת, ו**חיבור לתהליך העבודה** — התראה לחברי לוח על כל תשובה ושיוך אוטומטי לאחראי.
- מפת הפיצ'רים המלאה: [`docs/FEATURES_ROADMAP.md`](docs/FEATURES_ROADMAP.md).
- **אבטחה, פרטיות ונגישות מובנות** — ראו [`docs/SECURITY.md`](docs/SECURITY.md), [`docs/PRIVACY.md`](docs/PRIVACY.md).

עיצוב: מערכת העיצוב **SUBoard Spectrum** — ראו [`docs/DESIGN.md`](docs/DESIGN.md).

אפיון מלא ותוכנית שלבים: [`docs/PLAN.md`](docs/PLAN.md) · לפני פרודקשן: [`docs/PRODUCTION_CHECKLIST.md`](docs/PRODUCTION_CHECKLIST.md) · פריסה: [`docs/DEPLOYMENT.md`](docs/DEPLOYMENT.md)

## מבנה

```
packages/shared   סכמות Zod, טיפוסים וקבועים משותפים לשרת ולקליינט
apps/server       Fastify 5 + SQLite (better-sqlite3) — API, הרשאות, סשנים
apps/web          React 19 + Vite — ממשק RTL
docs/             אפיון, אבטחה, פרטיות, צ'קליסט פרודקשן, פריסה
```

## דרישות

- Node.js 20.19+ או 22.12+ (נבדק על 22.23)
- אין צורך בשרת מסד נתונים (SQLite מוטמע)

## התקנה והרצה לפיתוח

```bash
npm install
```

```bash
cp .env.example .env
```

ב-`.env` לפיתוח הגדירו `NODE_ENV=development` ו-`APP_ORIGIN=http://localhost:5173`.
לפיתוח בלי ClamAV אפשר `CLAMAV_SCAN_DISABLED_UNSAFE=true` (נחסם אוטומטית ב-production).

יצירת מנהל מערכת ראשון (הסיסמה נקלטת בצורה מוסתרת, לא דרך שורת הפקודה):

```bash
npm run create-admin -- --email admin@example.org --name "מנהל מערכת"
```

או נתוני הדגמה פיקטיביים (רק במסד ריק, חסום ב-production; הסיסמאות מודפסות פעם אחת):

```bash
npm run seed:demo
```

הרצה (API על 3000, ממשק על 5173 עם proxy ל-API):

```bash
npm run dev
```

פתחו http://localhost:5173

## בדיקות

```bash
npm test
```

```bash
npm run typecheck
```

- `packages/shared` — ולידציה, לוגיקת איחור, חישוב מועדי חזרה, ניגודיות צבעים (WCAG AA).
- `apps/server/test` — 134 בדיקות (כולל סדרות גלים A–E, H ו-I, ו-SSO/SCIM מול ספק OIDC מדומה עם בדיקות הרשאה לכל נתיב חדש; אוטומציות, מניעת לולאות, SLA, פריטים חוזרים, דוחות, ICS): התחברות, נעילה, Rate limit, CSRF, סיסמה זמנית, הרשאות ו-IDOR,
  ולידציה, לוח בקרה, כותרות אבטחה; TOTP מול וקטורי RFC 6238, הצפת סודות, MFA (replay, קודי שחזור, איפוס),
  התראות (opt-out, escape, תזכורת יומית), קבצים (נוזקה, הסגר, זיוף סוג, גודל, הרשאות) מול clamd מדומה, ייצוא CSV.

## Build ופרודקשן

```bash
npm run build
```

```bash
npm start
```

השרת מגיש גם את ה-SPA הבנוי (`apps/web/dist`) וגם את ה-API, כך שהכול באותו Origin.
לאחר פריסת build חדש של הממשק יש **לאתחל את השרת** (קבצים סטטיים נטענים באתחול).
גיבוי מקוון של מסד הנתונים:

```bash
npm run backup -- --out /secure/backups --keep 14
```

## החלטות טכנולוגיות (תקציר)

| רכיב | בחירה | חלופות | הערה |
|------|-------|--------|------|
| API | Fastify 5 | Express, NestJS | plugins רשמיים ל-helmet/rate-limit/cookie |
| DB | SQLite (WAL) | PostgreSQL | מתאים ליחידה; מעבר ל-PG מתוכנן בשלב 3 |
| סיסמאות | scrypt (N=2^15) | Argon2id | ללא תלות native נוספת |
| UI | React 19 + CSS ממערכת העיצוב SUBoard Spectrum | MUI, Tailwind | שליטה מלאה ב-RTL ונגישות, ללא CDN; גופן Rubik מתוך מערכת העיצוב (`npm run sync-design`) |

## רישיון ושימוש

מערכת פנימית. המסמכים המשפטיים בממשק (פרטיות, עוגיות, תנאים, הצהרת נגישות) הם **טיוטות** הדורשות אישור מקצועי.
